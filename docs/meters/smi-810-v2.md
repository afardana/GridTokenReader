# Meter profile: Smart Meter Indonesia SMI-810 V2

PLN prepaid kWh meter ("KWH Meter Prabayar"), single-phase, two-wire.

| Property | Value |
|---|---|
| Display | Segmented LCD with blue backlight. The main value shows the remaining kWh with 2 decimals (e.g. `59.23`), with unlit "ghost" segments to the left. |
| Screen code | A small 2-digit field top-right identifies the screen (`37` on the balance screen in the reference photo). Use it to reject frames showing other screens. |
| Status-credit LED | Green = enough credit, blinking red = low credit. |
| Pulse LED | 1600 imp/kWh (for optional real-time power measurement). |
| Keypad | 12 keys, used for token entry. Pressing keys changes the displayed screen. |
| Typical install | Inside a sealed metal box behind a clear cover, so no ambient light reaches it and the camera LED is the light source. |
| Supply limit | Depends on the breaker; the reference install has 25 A (≈5.75 kW max), which bounds how fast the balance can fall. |

## Capture notes

- The backlight may be off most of the time. The white camera LED lights the
  reflective LCD well enough, so tune `led` so the segments don't bloom.
- The clear cover is glossy. Angle the camera a few degrees, or diffuse the LED,
  to keep its reflection off the digits.
- ROI: main digits + the screen-code field + the status LED, all in one frame.

> Don't publish photos that show the meter's serial/ID number or barcode: the
> meter number identifies the customer account.
